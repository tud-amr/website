Redondo García" superscript: "1" - name: "Andreu Matoses Giménez" url: "https://andreumatoses.github.io/" superscript: "1" - name: "Javier Alonso-Mora" url: "https://autonomousrobots.nl/people/" superscript: "1" affiliations: - name: "TU Delft" superscript: "1" url: "https://tudelft.nl" end_date: 2026-10-20 description: "This thesis introduces a Hybrid Flow Matching planner that jointly generates the symbolic task plan and the continuous trajectories of the base and end-effector of a mobile manipulator, learned from only 109 teleoperated demonstrations. Plan-suffix augmentation multiplies the training samples, remasking lets the model revise low-confidence symbolic predictions, and the symbolic plan defines the points at which the robot replans in closed loop.
